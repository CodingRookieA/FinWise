# FinWise – AI-Driven Financial Assistant for Mutual Funds & ETFs

FinWise is an AI-driven financial assistant designed to support individual investors in making informed decisions about **Mutual Funds** and **ETFs**. The platform allows users to input their financial profiles and portfolio goals, enabling the AI to deliver context-aware guidance on portfolio allocation, fund selection, and overall investment strategy. All recommendations are powered by continuously updated market data and machine intelligence.

Unlike traditional robo-advisors, FinWise does **not** automate trades or manage assets on behalf of users. Instead, it focuses on **decision support**, emphasizing transparency, explainability, and user control.

## Key Differentiators

- AI-generated insights, **not** automated trading
- Canadian market focus, including regulatory and account-type awareness
- Portfolio-level personalization
- Explainable, performance-based recommendations

FinWise is ideal for investors seeking data-driven insights while retaining **full ownership** of their investment decisions.

## Target Users

FinWise is designed for three primary user groups:

1. **Beginner Investors**
   - New to mutual funds and ETFs
   - Seek guided support without financial jargon
   - Prefer actionable advice presented in plain language

2. **Self-Directed Investors**
   - Actively manage their own portfolios
   - Want data-informed insights without paying for traditional advisors
   - Value customization, transparency, and control

3. **Tech-Savvy Investors**
   - Early adopters of AI-powered tools
   - Comfortable with conversational interfaces
   - Want up-to-date insights without manual research overhead

## Market Sizing

FinWise operates at the intersection of personal investing and AI-powered financial tools.

### Personal Investing Market
- Tens of millions of Canadians hold mutual funds or ETFs through taxable and registered accounts such as **TFSAs** and **RRSPs**
- Mutual funds and ETFs account for **trillions** of dollars in assets under management (AUM) in Canada
- Retail investors increasingly seek digital tools that reduce reliance on costly financial advisors

### AI-Powered Financial Tools
- Adoption of AI tools in personal finance has grown rapidly, with millions of global users using AI for budgeting, investing, and financial planning
- Younger demographics show a strong willingness to explore AI-assisted financial decision-making before committing to human advisory services

**Conclusion:** The combination of a large retail investor base and increasing trust in AI-driven financial tools presents a sizable and growing market opportunity for FinWise.

## Insights from User Research

Early user research was conducted through online discussions and surveys on platforms such as Reddit and Quora (n = 20). The following insights informed product direction and feature prioritization.

### What Users Want
- Clarity over complexity: Users prefer explanations without excessive financial jargon
- Actionable insights: Guidance should translate into clear next steps
- Context awareness: Recommendations must respect account types (e.g., TFSA, RRSP)
- Explainability: Users want to understand **why** a recommendation is made

### Pain Points
- Beginner investors feel overwhelmed by financial terminology
- Self-directed investors want confidence that insights are based on current data
- Conversational and voice-based interfaces improve engagement, especially on mobile

### Feature Feedback
- Portfolio setup, AI chat, and data freshness were consistently ranked as most important
- Voice input was valued by mobile-heavy users
- Multi-portfolio comparison was viewed as useful but non-essential for early versions

## Feature Prioritization

Feature prioritization is based on:

- Core value delivery
- User research findings
- Technical feasibility
- Trust, accuracy, and compliance considerations for an AI-based financial product

### Priority 1: Must Have
These features are essential to deliver FinWise’s core value proposition.

- Login / Create Account
- Logout
- AI chat interface
- General financial guidance aligned with Canadian regulations and market conditions
- Grounded financial insights based on daily-updated ETF and mutual fund performance data
- Unbiased, performance-based recommendations independent of brand or fund reputation

**Rationale:**  
FinWise must ensure that all AI-generated responses are grounded, timely, and accurate. This requires securely associating user data with an account and injecting up-to-date market data into AI queries. Authentication and a robust AI chat interface are therefore foundational to the product.

### Priority 2: Should Have
These features significantly improve personalization, usability, and engagement.

- Portfolio setup (detailed investment distribution, e.g., number of shares held per fund)
- Collection of initial user financial information
- Portfolio-aware investment analysis tailored to individual holdings
- Save chat history
- Manage chat history

**Rationale:**  
These features enable deeper personalization and allow the AI to generate insights that reflect the user’s real financial situation. They also improve usability and continuity across sessions.

### Priority 3: Nice to Have
These features enhance flexibility but are not critical to early-stage functionality.

- Multiple portfolios under the same account with parallel chat sessions (e.g., comparing investment strategies under different income scenarios)
- Voice-to-text input

**Rationale:**  
These features benefit advanced users and scenario analysis but are not required to validate the core AI-driven value proposition in early releases.

## Priority Rationale Summary

FinWise prioritizes features that ensure:

- Trust and security through authentication and responsible data handling
- Grounded and current AI outputs via daily market data integration
- Meaningful personalization through portfolio-aware insights

By focusing first on accuracy, explainability, and relevance, FinWise establishes a strong foundation for user trust before expanding into advanced portfolio management capabilities.
